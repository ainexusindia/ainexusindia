# Go live (free)
1. github.com > repo ainexusindia/ainexusindia > Add file > Upload files. Drag in the `portfolio` folder (index.html, style.css, app.js, content.json, feed.json, admin.html). Commit.
2. Live in 1-2 min: https://ainexusindia.github.io/ainexusindia/portfolio/
3. Auto-update: Add file > Create new file. Name it `.github/workflows/youtube-feed.yml`, paste the contents of youtube-feed.yml, Commit. Then Actions tab > "Update YouTube feed" > Run workflow (enable Actions if asked). It refreshes every 6 hours.
4. Homepage link: add <a href="portfolio/">Creative Portfolio</a> to your root index.html nav.
# Update on the go
- New video/short: appears automatically under "Latest from the channel".
- Feature it as a project, or add an image: open portfolio/admin.html on your site, fill the form, copy the snippet, paste it into portfolio/content.json (pencil icon on github.com), Commit.
- Images: upload to portfolio/images/ (Add file > Upload files), then add the snippet from admin.html.
